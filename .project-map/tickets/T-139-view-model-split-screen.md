## What to build

来源：用户 2026-10-23 在本 session 逐字（第 2 条）：“2.项目视图在同一个屏里分屏展示任务列表,点进去可以在该屏里分屏展示各个 agent,在 单独的 agent,比如 worker,执行主控界面只展示他自己”

现状：项目视图只载入项目普通终端；任务视图载入任务会话再加上项目所有普通终端（`app/main.ts` prepareSelection 约 600–630 行），所以点 worker 会带出主控，点主控却看不到 worker。

目标三层，同一块屏幕内导航：
- 项目视图：分屏展示该项目的任务列表（每个任务一格）。
- 点进某个任务：该屏内分屏展示这个任务的各个 agent 会话。
- 点单个 agent（worker、执行主控等）：只显示它自己，不带别的窗格。
- 项目的普通终端（含用户自己启动、经角色申请成为主控的终端）作为项目层的会话；它只在“它自己”的视图里出现，不再混进任务视图。

保持：窗格布局持久化、输入凭据只发给可输入窗格、ended 会话只读查看。
