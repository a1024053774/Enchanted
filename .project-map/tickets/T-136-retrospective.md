## What to build

来源：用户 2026-10-22 逐字：“107 吧多 worker 做出来，早期的调研票关掉，然后还缺的都做”。 native-cli spec 第 8 节“复盘”。

- 启动：界面“立即复盘”，或按周期（默认每周一 9:00，可改可关，存在 a2a 自己的库）。
- 执行：每次选 CLI、模型、思考强度，默认 Claude Code、Opus 5.5（`claude-opus-5-5`）、medium；在普通窗格里跑，本身也有启动记录。
- 复盘包由脚本备好：时间范围（默认上次复盘到现在）内的任务、门禁逐项结果与打回原因、审查结论、打分、问题上报、用户输入与介入、面板问答、提交尾注汇总、指标快照（T-134）、轨迹归档路径（T-135）。
- 权限：只读代码和数据，只写自己的报告。
- 产出：中文报告存项目的 `findings/`（没有这个目录的项目存工作台数据目录）；改进建议逐条放上面板，用户批了才由构思主控写成 ticket 或改角色卡。

## Acceptance

- [ ] 复盘包：在已知内容的夹具库上生成，各项与库读回一致（期望由测试按场景构造）；时间范围外的不进包。
- [ ] 真实入口：界面点“立即复盘”，选 Claude Code 与模型（真实运行按用户指定用 haiku 以控制成本），会话只读、只写报告；报告落在 `findings/`，建议出现在面板。会话越权写别处被拒。
- [ ] 周期：时间到点启动一次（测试用可注入的时钟），关闭后不再启动。
- [ ] 截图与复现命令入证据。

## 不做

不自动把建议写成 ticket；不做收益主张。
