## What to build

来源：用户 2026-10-19 在执行主控会话逐字："这个也要改进,我想要和 herdr 一样,我在这里可以随意开终端,然后有[截图] 这些按钮,可以分屏之类的. 不能我自己什么也干不了吧,我不喜欢用命令行创建各种命令,这种交给 agent 互通就行了."（截图是 Herdr 窗格右键菜单：Rename pane、Split right、Split down、Zoom、Send right-clicks to pane、Close pane。）执行主控报告：收件箱 `20261019T110900Z-executor-needs-decision-001`。

用户逐字选项（2026-10-19，会话"a2a-构思主控"，AskUserQuestion）：
- 终端归属："随意开,可不属于任何项目 (Recommended)"，选项原文："打开应用就能开终端，工作目录默认你的家目录或你选的目录，像 Herdr 一样。终端可以后来再关联到项目。"
- 布局保存："保存布局和名字，重开后恢复 (Recommended)"，选项原文："分屏排列、窗格名字记在 a2a 自己的库里，重开应用按原样排好；普通终端里的进程不自动重跑（显示“已结束”），agent 窗格照现有恢复规则。"

这**取代 T-104 里"普通 shell 窗格属于项目、新建要先选任务"的部分**：终端可以不属于任何项目；有项目时仍可选项目目录作 cwd。T-104 其余语义不变（不经门禁、输入不当作对 agent 的输入、事件流只记创建/关闭不记输入内容）。

按 tracer bullet，先打通一条：应用启动即可"新建终端"（无项目也行）→ 分屏 → 重开恢复；再补菜单其余项。

1. 新建终端：工具栏/空状态里有入口；cwd 默认家目录，可选目录；不要求已有项目或任务。
2. 窗格右键菜单（沿用 Herdr 的六项，中文标签）：重命名窗格、向右分屏、向下分屏、放大（再点还原）、"把右键发给窗格"（开启后右键事件按终端鼠标协议转发给里面的程序，如 vim/tmux，而不是弹菜单）、关闭窗格。
3. agent 窗格（主控/worker/reviewer）同样有这个菜单里的分屏、放大、重命名；**关闭受管 worker 窗格**仍走现有门禁语义，不得因菜单绕过；在受管 worker 窗格直接输入仍记人工介入。
4. 布局与名字存进 a2a 自己的库（沿用现有"窗格集"持久化），重开恢复排列与名字；普通终端显示"已结束"，不自动重跑；agent 窗格照 T-096 规则。
5. 界面文案中文，走 `frontend-production` 的去 AI 味要求；菜单键盘可达；窗口缩放时分屏比例合理。

## Acceptance

- [ ] 红态：当前无项目时无法开终端、无右键菜单。绿态：真实 Electron（打包后的 `.app` 或同一构建），空库启动 → 新建终端 → 向右分屏 → 向下分屏 → 放大/还原 → 重命名 → 关闭，每步截图。
- [ ] 重开：关闭并重开应用，排列与名字保持，普通终端显示"已结束"，agent 窗格按 T-096 规则。
- [ ] 右键转发：在终端里跑一个会开鼠标上报的程序（如 `less` 或 vim 开 `set mouse=a`），开关打开时程序收到右键，关闭时弹菜单。
- [ ] 反例：关闭受管 worker 窗格走门禁语义（不是直接杀）；普通终端输入不进 agent 输入记录；关闭终端后子进程确实结束。
- [ ] 不动门禁入口与操作锁语义；`project_map.py status` 0 问题。
