## What to build

来源同 T-105（用户逐字原话见该票）。现状：新建项目、新建任务（14 字段任务卡）、启动主控、派 worker 都只能走 gates CLI；用户首次打开 `/Applications/a2a.app` 只看到"还没有项目"。

用户逐字选项（2026-10-19，会话"a2a-构思主控"，AskUserQuestion）："界面有入口 + 主控代办 (Recommended)"，选项原文："界面上有“新建项目”“新建任务”按钮，只填名字和目标；任务卡的 14 个字段由主控 agent 补全后交你确认。你不用敲任何命令，也可以直接对主控说话让它建。"

1. "新建项目"：选一个现有 git 仓库目录（或让后台 `git init` 一个新的，要用户在界面确认），填名字；后台经**现有门禁命令**注册，界面不另做一套。
2. "新建任务"：只填标题和目标；后台起一个**主控窗格**（Claude Code，沿用 `controller_start` 和 T-093 的正常登录入口，权限与启动参数不变），把"补全任务卡 14 字段"的请求写给主控，主控用门禁命令生成任务卡草稿，**界面展示草稿，用户点确认才注册任务**；用户可编辑后再确认。
3. 用户也可以直接在主控窗格里对主控说"建个项目/任务"，走同一条门禁命令；不新增第二条创建路径。
4. 界面入口随时可用：没有主控窗格时，"新建任务"会先起一个（说明会占用一个 Claude 根回合，需用户点确认）。
5. 提示词管判断、脚本管事实：任务卡字段的合理性由主控和用户判断，门禁只校验格式（缺字段、完成条件不是命令就拒收）。
