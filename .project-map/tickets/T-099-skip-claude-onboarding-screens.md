## What to build

用户 2026-10-18 对执行主控说（经执行主控转述，会话"A2A 客户端整体评估"，非构思主控直接听到）："我在想能否把这个初始化流程通过配置来绕过他,这样就不会显示了,如果不行的话,也没事,我一般不用 claude 做分工,我一般自己手动启动"。用户明确说**不行也没事、平时自己手动启动**，所以本票低优先级。

事实（T-093 探针 probe-08、probe-10，Claude Code 2.1.302）：在 a2a 自己的隔离配置里写 `hasCompletedOnboarding=true`，再加上"只信任该隔离目录"的状态，CLI 直接停在输入提示符，不用按任何键。这两项是 2.1.302 的**内部字段**，没有公开设置，升级后可能失效。

1. 工作台起 Claude 主控时，在每会话的隔离配置里预置这两项；只写隔离目录，不写 `~/.claude`。
2. 配版本核对：CLI 版本不符 T-091 的配置值（从配置读取、启动 `--version` 核对）就报错，不假设字段仍有效。
3. 预置后若 CLI 仍停在初始化屏（字段失效），要识别并报"初始化未跳过"，不吞键、不盲按回车。
