## Question

如何在主控结束或回收研究任务时，检查下一步授权、停止依据和可保留的阶段产物？
实例是首轮把新项目缺少现成代码当作整体阻塞，以及 T-006 后在仍有后续任务时停止。
研究 worker 两轮均未落最终报告，主控在观察到进展后仍依靠等待和临场判断决定中断。
证据：[F01、F02](../../reports/a2a-session-retrospective-2026-10-06.zh-CN.md)、
[E01–E08](../../evidence/2026-10-06-session-review-01/excerpts.json)。

交接检查至少要求：本阶段产物、尚未完成项、已授权可继续项、确切停止理由与下一负责人。
缺少现成代码不自动等于方向阻塞，等待超时不自动等于 agent 挂起。
研究任务应有有界的中间证据与交付条件，不能只扩大等待时长。
检查不替用户授权、不自动跨越重大决策，也不把单 worker ticket 边界当作主控必须停止。
复用旧会话作为缺口样本，并用包含真实停止条件的样本证明检查不会强迫越界继续。

本票记录待办，不改变当前产品的 run 截止语义。
