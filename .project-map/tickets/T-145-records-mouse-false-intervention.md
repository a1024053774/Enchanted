## What to build

来源：用户 2026-10-23 在本 session 逐字（第 8 条）：“8.记录界面现在应该是误判,这误判太多了,”

现状：记录页 118 条里 114 条是人工介入，内容是 `[<35;9;3M` 这类序列。它们是终端鼠标移动上报（SGR 鼠标模式），xterm 的 `onData` 把它们当键盘输入发给窗格，门禁因此记“窗格键入 / 人工介入”。

1. 区分真实键入与终端控制上报（鼠标 `CSI < … M/m`、焦点 `CSI I/O`、设备状态回复等）：控制上报不进用户输入记录，也不算人工介入；仍要原样送给 CLI（它们开了鼠标模式要用）。
2. 判别按终端协议的序列格式，这是我们自己产生的协议标记，不是对用户文字意图的分类（见记忆“不用正则判断意图”：这里不判断用户说了什么）。
3. 已有的误记录保留不改，页面可标注，不删除（追加式）。

## Acceptance

- [ ] 真实 Electron：在受管 worker 窗格里只移动鼠标、滚动，记录页不新增人工介入；真正打字一次则新增一条。
- [ ] 红态：修前鼠标移动产生记录。
- [ ] 开着鼠标模式的 CLI 仍收到鼠标事件（不被一并吞掉）。
