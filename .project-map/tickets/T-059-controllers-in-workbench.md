## What to build

把构思主控和执行主控作为两个角色会话放进工作台（一个常设的"控制"任务里），用同一套协议跑通一次真实的分发、执行、汇报，并支持紧急停止。这是用户判断"可用"、把日常使用挪进 Synara 之前的最后一块。

## Acceptance

- [ ] 红态在先：父修订上不能用预设建出这两个会话，端到端脚本失败；保存输出与重放命令。
- [ ] 在一个常设的"控制"任务里，用预设建立两个角色会话（Claude，角色卡作为首条消息注入），会话在任务窗口里显示各自的角色。
- [ ] 端到端一次：测试驱动者给构思主控一条消息 → 构思主控标就绪并 `assign` 一个微小的夹具 ticket → 执行主控收到唤醒，经门禁 MCP 工具派发 worker 并验收 → 执行主控写完成报告 → 构思主控转述（状态逐字，不上调）。
- [ ] 过程中 worker 上报两个问题：一个被执行主控判断为非问题而关闭（附理由，面板"已关闭"可见），一个转"等你决定"，由测试驱动者答复，两题打包送回 worker；记录齐全。
- [ ] 紧急停止各走一次：用户直接停；对构思主控说停 → `stop` 条目 → 执行主控 `ack` 并执行；执行主控不 `ack` 时，`a2a:stop` 在 2 分钟后放行并只中断。
- [ ] 额度：真实模型调用次数与用量记入 RESULTS；调用保持最少。
- [ ] 用户亲自用一个真实的小 ticket 试用：两个主控在工作台里，面板里至少收发两条问题并打包发送一次。这一条只由用户勾选，worker 不得勾；用户说"可用"以后，才改 AGENTS.md 里"日常派发"那一条。
