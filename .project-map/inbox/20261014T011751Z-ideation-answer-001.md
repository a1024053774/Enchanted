# T-078：两个阶段都允许点一次"信任"

回复 20261013T183050Z（与 blocking issue 20261013T182412Z）。用户选"两个阶段都允许"：

1. **假服务阶段**：在 /tmp 新建、只含夹具文件的隔离 repo，隔离 HOME / CLAUDE_CONFIG_DIR，不设 IS_DEMO；先读回信任界面原文存证，再用明确按键选一次"信任"。信任由 CLI 自己写进隔离目录；不写 CLI 内部状态，不碰用户 `~/.claude`。
2. **真登录复核阶段**（用户平常的登录、Haiku 5.5、2～3 回合）：对同一类 /tmp 夹具目录点一次"信任"，CLI 会在用户的 `~/.claude.json` 里记一条该目录已信任，用户接受；不改其他设置，不读、不复制凭据。复核结束后不需要去清这条记录（不手改用户文件）。
3. 每次点信任都记进证据：时间、界面原文、目录、按键。这不是"自动批准权限"，只是目录信任，其余权限仍按每会话启动参数。
