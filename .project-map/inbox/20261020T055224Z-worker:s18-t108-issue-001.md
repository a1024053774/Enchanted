T-108 无模型真实入口验证发现产品关闭缺口（非阻塞上报）。

现场：/private/tmp/t108-native-e2e-01.json；fixture /private/tmp/t078-2-t108-a9ttufj7。
daemon_stop 已执行且返回 ok，daemon.pid 已移除，但 Claude PID 32252 仍运行。
pane_process_info 记录 shell PID/PGID 32250、Claude PID/PGID 32252。

根因：workbench/src/panes.ts:1228 terminate 仅对 role=shell 的窗格采集、核验子进程；controller/worker 路径只等待 PTY shell onExit。daemon.ts:117 等待 panes.shutdown 后即记 daemon_stopped，不能证明独立进程组的原生 CLI 已退出。

影响：关闭后台可能残留原生 CLI；T-108 先前测试把 daemon.pid 消失当作全部退出，遗漏该情形。建议主控单独分票修复按身份核验的原生会话退出。T-108 不扩大到产品关闭语义，先修测试：保留身份，finally 在停止 daemon 后结束本次独立 CLI 并核验两进程均已退出，失败记 INCOMPLETE。旧现场提供 RUN-OUTSIDE-CLEANUP-01.sh，逐个核验完整 session、debug 路径、启动时间和 argv，再发信号；不删除现场。
