在专门夹具里冻结窗口取证，证据见 evidence/2026-10-11-batch13/T-076/card-1/outside-attachments-01/windows/：
- creating 窗口：attachments 里已有该行，但现有事件无法重建它，因为 creating 状态没有对应事件。结论：不一致。
- active 窗口：已经写入 active 行，但 attached 事件尚未写入，现有事件无法重建该行，因为 saveAttachment 与 attached 事件不在同一个事务里。结论：不一致。
正常流程走完后，最终的行一致，但这不能证明中间窗口是完整的。
