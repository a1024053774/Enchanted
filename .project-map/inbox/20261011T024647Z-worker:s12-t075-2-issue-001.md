## 观察到的失败

2026-10-11 UTC，本机 `/opt/homebrew/bin/git` 为 `git version 2.52.0`。在 /tmp 自建的真实 Git 仓库与 linked worktree 中，执行 PLAN 第 3 节提议的事务：

```text
start
update refs/heads/main <M> <G>
option no-deref
symref-verify HEAD refs/heads/main
prepare
```

`start` 返回 `start: ok`；`prepare` 退出 128，stderr 原文：

```text
fatal: prepare: multiple updates for 'HEAD' (including one via its referent 'refs/heads/main') are not allowed
```

本结果证明批准方案中的“更新当前工作分支 + 显式 symref-verify HEAD”组合无法在该 Git 版本准备成功。它不是缺依赖、沙箱拒绝或产品门禁红态；也不能据此说 `symref-verify` 单独不受支持。尚未运行单独命令的探针。
