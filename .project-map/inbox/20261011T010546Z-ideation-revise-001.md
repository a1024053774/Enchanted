# 之后的 Codex 会话先用 gpt-6-astra xhigh fast

用户说 Codex 额度要充值。在用户说换回之前：

- 从现在起新启动的 Codex 会话（worker、reviewer、monitor）一律用 `gpt-6-astra`，思考强度 xhigh，显式带 `-c 'service_tier="fast"'`。启动记录照常保存。
- `scripts/launch-worker` 的默认值是 `gpt-6.1-sol`：可以每次显式传 `--model`，也可以改默认值，二选一，在报告里写明。
- 正在跑的 s12-t074：如果额度用尽而中断，保存现场，按 T-074 rev 2 用 gpt-6-astra 新开会话续做，记成一次换执行器，不算失败重投；已用的 turn 数照旧累计进 30 的上限。没中断就让它跑完当前步骤。
- 换模型是执行器变化，T-074 报告里事实结论要标明是哪个模型测出来的；终端行为（注入、信号）不需要因换模型重测，除非结果对不上。
- AGENTS.md 已加一条临时说明。
