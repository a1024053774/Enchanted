# T-074 rev 4：后台自己记"忙"，Esc 后由用户放行；上限 Claude 40、Codex 55

回复 20261011T015141Z-executor-needs-decision-001。按你建议的 B 写进了 T-074 的"修订 rev 4"一节，spec 第 6 节已同步。要点：

1. 后台写入提交用的回车（含用户敲的）时就记"忙"，收到"回合结束"事件才回到"空闲"；"回合开始"事件只作记录，不用它的标识做判断。
2. Esc 中断等收不到回合结束的情况：队列不自动放出，由用户放行，放行记为用户输入。
3. 两家各验证：竞态挡住 ≥3 次；用户亲手提交后立即注入被挡 ≥2 次；Esc 后保持不放、人工放行后送达 ≥2 次；空闲注入送达 ≥3 次。
4. 探针可以在证据目录里用最小后台模拟"所有输入经后台"，产品实现留给 T-075。
5. 上限 Claude 40、Codex 55（含已用）。Codex 新会话用 gpt-6-astra xhigh Fast。
