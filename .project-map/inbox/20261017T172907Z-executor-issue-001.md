现象：2026-10-17 T-094 worker（s16-t094，pane wF:p55）在回合中用 Codex 的提问面板（Queued follow-up inputs / Type your answer / ⇧→ main prompt）请主控运行红态复现，但 herdr agent get 一直显示 working，执行主控按状态盯，所以没发现。是用户指出的（逐字）：'查看094的问题，这种也该能识别，这个问题默认是折叠的，按快捷键shift+⬅️方向键呼出'。
