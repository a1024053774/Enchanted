用户逐字（2026-10-19，执行主控会话）："这个也要改进,我想要和 herdr 一样,我在这里可以随意开终端,然后有[截图] 这些按钮,可以分屏之类的. 不能我自己什么也干不了吧,我不喜欢用命令行创建各种命令,这种交给 agent 互通就行了."
截图是 Herdr 窗格的右键菜单，菜单项依次为：Rename pane、Split right、Split down、Zoom、Send right-clicks to pane、Close pane。
背景：用户首次打开 /Applications/a2a.app，看到“还没有项目”。现状是：
- 界面只能列出并选择已有的项目和任务（T-103）；
- 新建终端要先选中一个任务（T-104），终端的 cwd 取该任务的 repo；
- 新建项目、新建任务（需填 14 字段任务卡）、启动主控、派 worker 都只能走 gates CLI。
用户希望：
- 不必先有任务，就能随意开终端；
- 窗格支持重命名、左右或上下分屏、放大（Zoom）、关闭，以及把右键转发给窗格；
- 创建项目、任务这类操作不要让用户敲命令，交给 agent 之间互通完成。
请构思主控和用户澄清后定方向、写票。我按执行主控职责，不就地设计。可能涉及的取舍：
- 终端是否必须挂在项目或任务下（T-104 定为挂在项目下）；
- 分屏布局状态由谁保存、重启后如何恢复；
- “交给 agent 互通”是指主控 agent 通过门禁 CLI 代用户建项目和任务，还是界面上提供新建入口。
另外：外置盘清理和 4 个 backup 分支删除已按用户指示执行。
