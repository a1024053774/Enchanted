---
title: Install Muster
description: Install, update, and verify Muster on Linux and macOS.
---

Muster ships as a single binary for Linux and macOS.

## Install

Run the installer:

```bash
curl -fsSL https://muster.dev/install.sh | sh
```

The installer downloads the right release binary for your platform and places it on your PATH.

## Install with Homebrew

If you already use Homebrew:

```bash
brew install muster
```

## Install with mise

If you already use mise:

```bash
mise use -g muster
```

## Verify

Start Muster:

```bash
muster
```

If your shell cannot find `muster`, restart the terminal or check that the install directory is on your PATH.

## Update

Muster checks for new releases and notifies you in the app. You can update manually:

```bash
muster update
```

`muster update` is for installs managed by Muster's own installer. Homebrew, mise, and Nix installs are updated through those package managers instead.

Muster uses the stable update channel by default. To opt into preview builds from `master`, set the channel:

```bash
muster channel set preview
```

Switch back to stable the same way:

```bash
muster channel set stable
```

For direct installs, changing channels also checks that channel and installs its latest binary. If that update fails, run `muster update` to retry from the configured channel.

Preview builds are GitHub prereleases published from the current development branch. They are useful when you want fixes before the next stable release, but they can regress. Homebrew, mise, and Nix installs do not use the preview channel.

By default, `muster update` installs the new binary and leaves compatible running sessions alone. If an update changes Muster's client/server protocol, Muster asks whether to stop the old server after installing. Stop the old server to use the new version. Stopping exits pane processes. For the default session, run `muster server stop`, then run `muster` again. For a named session, run `muster session stop <name>`, then run `muster session attach <name>` again.

To opt into experimental live server handoff for supported running sessions, run:

```bash
muster update --handoff
```

Live handoff does not apply to Homebrew, mise, or Nix package-manager updates. For those installs, update with the package manager, then restart that Muster session when you are ready to use the new server. If a running session still uses the old server, stop it with `muster server stop` or `muster session stop <name>`, then run Muster again.

## Install with Nix

If you already use Nix, Muster provides a flake that builds Muster from source:

```bash
nix run github:musterdev/muster/v0.x.y
nix build github:musterdev/muster/v0.x.y
nix profile install github:musterdev/muster/v0.x.y
```

Replace `v0.x.y` with the latest release tag. You can omit the tag to track `master`, but release tags are recommended for normal installs.

The flake also exposes a development shell:

```bash
nix develop github:musterdev/muster
```

Update through the same Nix workflow you used to install Muster. For a profile install, list your profile entries and upgrade the Muster entry:

```bash
nix profile list
nix profile upgrade <index-or-name>
```

If Muster is an input in your own flake, update that input and rebuild your system, Home Manager, or development environment:

```bash
nix flake update muster
```

## Download manually

You can also download a binary from [GitHub releases](https://github.com/musterdev/muster/releases).

Choose the asset that matches your system:

| System | Asset |
| --- | --- |
| Linux x86_64 | `muster-linux-x86_64` |
| Linux aarch64 | `muster-linux-aarch64` |
| macOS Intel | `muster-macos-x86_64` |
| macOS Apple silicon | `muster-macos-aarch64` |

Make it executable and move it somewhere on your PATH.

```bash
chmod +x muster-linux-x86_64
mv muster-linux-x86_64 ~/.local/bin/muster
```

## Requirements

Muster supports Linux and macOS. Native Windows support is not available yet; use Muster inside WSL for now.
