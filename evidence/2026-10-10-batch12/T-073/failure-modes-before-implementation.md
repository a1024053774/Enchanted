# T-073 实现前失败方式与验证面

- 启动：错误身份/版本、损坏记录、重复 agent、Herdr 启动失败；失败保留 pane 与记录，不重试、不触碰他人。
- 提交：环境缺字段、启动记录不存在或身份不符、原钩子缺失/失败、已有尾注重复或旧身份、no-verify、amend/rebase/merge；真实 Git 检查，真实 Codex 检查一次两提交。
- 记录：并发追加、截断 JSONL、无效行；持锁校验与追加，拒收时字节不变。
- 打分：缺分数/理由/备注，越界分数，不完整事实字段，放弃带分，用户分覆盖执行主控分；从独立输入经 CLI 写入并读回，至少一条缺字段反例、并发和损坏记录。
- Codex 默认环境过滤前提按执行主控决定 01 作废；不加覆盖。red02 保留实测反例，未来缺尾注由完成条件与门禁核对拒收。
