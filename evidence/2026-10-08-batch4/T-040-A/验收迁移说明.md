## 18 项逐项核对

下表承接 T-037 的 [边界差异](../../2026-10-07-synara-batch2/T-037/acceptance-differences.md)。本次只有默认入口、证据输出与快照位置迁移；没有再次改变运行时场景或答案。

| 项 | 已批准的原生场景 | 本次保留的关键断言 |
| --- | --- | --- |
| 1 | 正常 run | 显式 submit、真实候选、独立 oracle、集成引用回读、只回收自己的 thread |
| 2 | 同 turn 临时工具活动 | 所有权保持，正常完成 |
| 3 | thread 仍在而 turn 更换 | 不验收、不集成、不误回收 |
| 4 | verify 绑定 expected attempt | 真实验收门禁与 oracle |
| 5 | integrate 绑定 expected attempt | 真实引用和 reflog 更新 |
| 6 | 已有 dispatch/submit/verify/integrate/reclaim | done 不接受，显式 submit，一次 oracle，回收归属保持 |
| 7 | 有 commit 但没有 submit | 仍为 2 秒期限，run_deadline，零 oracle，引用/reflog 不变 |
| 8 | 并发重复 run | 批准的 wait 输入 30 秒不变；重复请求仍须 3 秒内 run_busy，一个 attempt 和 prompt |
| 9 | 非法等待值 | 原全部非法值拒绝，无业务、Git、thread 或 prompt 副作用 |
| 10 | 原 run 被 replacement attempt 取代 | 批准的 wait 30 秒和外部观察屏障 60 秒不变；旧 run 不验收、集成、回收 replacement |
| 11 | oracle 拒绝 | 实际 oracle 非零，引用不变，只回收自己的 thread |
| 12 | 启动阶段等待权限 | 零 prompt、零回收，保留现场 |
| 13 | 投递后等待权限 | 一次 prompt，不自动回答、重投递或回收 |
| 14 | worktree 身份未知 | 零 oracle，保留未知对象 |
| 15 | stale verify/integrate guard | stale_attempt，状态/Git/历史不变，accepted 幂等仍核对归属 |
| 16 | 指定历史 reclaim | 不动 current/foreign；历史重放无额外副作用，跨任务与未知 attempt 拒绝 |
| 17 | 成功后同 attempt reclaim 重放 | 幂等，不重复 stop/archive，业务与 Git 不变 |
| 18 | 活跃验收期间 attempt guard | operation_busy，不起第二 oracle，原操作仍可完成 |

`assertion-preservation.json` 是静态核对记录，只证明迁移未改这些测试方法，不代替行为验收。删除前后的 command/trace 来自新的实际运行，分页 oracle、Git CAS/reflog 与只读 SQLite 观察仍是独立的业务证据。将入口指向不存在的旧文件，只证明验收会拒绝已删除入口，不将它冒充产品逻辑 mutant。
