Enchanted 0.1.2：主控改在项目终端里申请，加上问题、记录、指标和 Reflect 四个页面。

- 主控：在项目终端里用自己的命令启动 Claude Code，经 `a2a request` 申请成为构思主控或执行主控，你在界面上批准才生效；批准执行主控时可以选它的上级构思主控。终端主控用 `a2a` 派发 worker，可选 CLI，worker 与审查员启动时就定好身份，自动挂到侧栏。
- 侧栏：项目行第二行显示分支和领先、落后的提交数；agent 树按层级显示七种状态。
- 问题：worker、审查员、监视器上报的范围外问题在这里答复、稍后再看或关闭；标了“阻塞”的只有你能关闭。
- 记录：你亲手打的字、答复和审批；在受管 worker 窗格里的输入记为人工介入。
- 指标：模型使用、一次到位率与打回原因、你的注意力消耗、打分汇总，从记录现算。
- Reflect：项目历来的主控与会话树和打分；复盘可以手动或定期启动，定期复盘默认关闭，改进建议要你批准。
- 模型、思考强度和 Fast 不再写死，在设置里按角色修改；不再限制原生 CLI 的版本。
- 同一项目可以多个 worker 并行交付；产品里的 Codex worker 与审查员使用你的 `~/.codex`。

安装包适用于 macOS arm64（Apple Silicon）。解压后将 `Enchanted.app` 放入“应用程序”。

本包使用 ad-hoc 签名，未经 Apple 公证。首次打开如被系统拦截，可在访达中右键选择“打开”；必要时运行：

```sh
xattr -dr com.apple.quarantine /Applications/Enchanted.app
```

使用前先安装并登录官方 Claude Code 或 Codex。bundle id 与后台数据目录保持不变。

这是开发中的初版，已知边界与未完成事项见仓库 README 和项目地图。
