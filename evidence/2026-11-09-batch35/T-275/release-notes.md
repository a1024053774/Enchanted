Enchanted 0.1.7：右侧新增 Git 图和改动面板；问题计数、任务条、指标页和 Reflect 页在数据多时更好读；修了 Codex worker 几种卡住、回收不了的情况。

新面板：

- 顶栏“面板”打开右侧面板位，可拖宽。面板跟着最后聚焦的窗格换目录：普通终端取它当前的目录，受管窗格取它的 worktree；也可以固定。
- Git 图：提交表和泳道，未提交的改动用虚线接在 HEAD 上；点提交看作者、父提交、提交说明和改动的文件，再点文件看 diff。右键和“仓库操作…”里的写操作都先确认。
- 改动：冲突、已暂存、未暂存分组列出，每个文件带 +/-；暂存、取消暂存、丢弃（先确认）、写说明提交；diff 折叠长段未改动内容、行内强调改动部分；可以和自动找到的基线分支比较。在 diff 里选几行写审阅备注，整批作为粘贴发到聚焦的终端。
- 跟随的是门禁管理的任务 worktree 时，两个面板都只读，主进程也拒绝写操作。

界面：

- 任务在门禁里已经结束（已集成、已放弃、已升级）后，挂在它上面的未决问题改为“可能已随任务结束失效”，不再计入“等你决定”，由你确认后关闭。
- 任务条最前面是“全部 N 个”下拉框，最新在前；条上只留当前任务和最近 3 个，不再横向滚动。
- 记录页的任务筛选写“编号　任务目标第一句”；记录页按任务、会话分区，最新在前。
- 指标页顶部先给总数，章节可跳转，会话按任务分组；Reflect 页开头按状态计数，会话多时按任务分组，没有进行中会话的旧组先收起，评分理由收进“理由”。
- 问题卡的“重新打开”能用了；Codex 回合带错误结束时，侧栏显示“回合出错结束”，不再一直转圈。

主控与门禁：

- worker 回合因 cd 进子目录、上下文压缩被误判不可信的问题已修；真不可信时回合照常结束，交付记为拒收并告知执行主控。
- Codex、agy、opencode worker 回合不可信时 Stop 照常结束，能回收、能派新 worker。
- 经 dispatch 派出、还没交付过的 Codex worker 能回收；原生会话号晚于启动期限出现、Stop 前就贴入回执、窗格创建后绑定前失败，这几种情况都不再卡住交付和回收。
- 审查材料不再整份内联，Codex 审查员不会因输入过长被拒。
- 事件表加索引，会话多时界面读事件更快。

升级提醒：

- 换版后 macOS 会收回 Enchanted 访问“文稿”等文件夹的授权（本包是 ad-hoc 签名，每个版本都算新的应用）。终端里的 CLI 读这些目录时会停下来等系统弹窗，请本人允许一次。
- 内带的 hc 仍是固定版本 0.1.15；你自己装的 Herdr 和它的 core 不受影响。

已知限制：

- 启动核对失败、又没绑定原生会话的已停止 attempt 还回收不了（T-267）。
- run 的验收碰上门禁忙时会暂停（T-255）；Codex 审查员还不跟随 worker 的模型与强度（T-256）。
- 只支持 macOS（Apple 芯片）；CLI 支持 Claude Code、Codex、agy、opencode 四种。

安装包适用于 macOS arm64（Apple Silicon）。解压后将 `Enchanted.app` 放入“应用程序”。

本包使用 ad-hoc 签名，未经 Apple 公证。首次打开如被系统拦截，可在访达中右键选择“打开”；必要时运行：

```sh
xattr -dr com.apple.quarantine /Applications/Enchanted.app
```

使用前先安装并登录至少一种支持的 CLI。bundle id 与后台数据目录保持不变。
