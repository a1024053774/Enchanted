# Enchanted 0.1.3 真实使用实测（lcu，2026-10-25）

## 范围

- 版本：/Applications 中新装的 0.1.3（签名核对通过），用户真实数据目录与后台。
- 项目：一次性仓库 `/private/tmp/a2a-lcu-demo`（README.md、stock.csv）。
- 操作者：构思主控用 lcu 操作 Enchanted 窗口；应用内主控为 claude-haiku-5-5，worker/审查员为默认 claude-sonnet-5-5。
- 走到：打开项目 → 新建终端 → 启动 Claude → 申请执行主控 → 界面批准 → 两张票并行派发 → 交付 → 独立审查打回 → 修订重派 → 两张票都经门禁集成到 `work/demo`（9312a70）。
- 启动方式偏差：本轮从 Herdr 里用 `open` 启动应用，应用终端继承了 `HERDR_*`、`AI_AGENT` 等变量；用户从 Dock 启动不会有。下列结论不依赖这些变量。
- 截图：`evidence/2026-10-25-batch25/lcu-real-use/`。系统弹窗那张全屏截图含用户其他窗口内容，没有入库。
